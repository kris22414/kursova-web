# Проект "Вкусни Рецепти" – Контейнеризация с Docker Compose

Това ръководство описва процеса по контейнеризация на уеб приложението "Вкусни Рецепти". Приложението е разработено на PHP и използва MySQL база данни за съхранение и управление на рецептите. Всички компоненти са конфигурирани да работят съвместно в изолирана Docker среда чрез **Docker Compose**.

---

## Проектна структура

Файловете в проекта са разпределени по следния начин:
* `src/` — съдържа основните PHP скриптове (`index.php` и `db.php`).
* `styles/` — съдържа CSS стиловете за визуализация на потребителския интерфейс (`style.css`).
* `kursova_2.sql` -  базов SQL скрипт за инициализация на базата данни.
* `Dockerfile` — дефинира стъпките за компилиране на персонализирания PHP-Apache уеб сървър.
* `compose.yml` — управлява конфигурацията, обемите и свързаността между контейнерите.

---

## Архитектура на системата

Приложението е разделено на две основни изолирани услуги:

### 1. Уеб сървър (`web`)
* **Основа:** Официален образ `php:8.2-apache`.
* **Допълнителна конфигурация (Dockerfile):** Инсталиран е модулът `pdo_mysql`, който позволява на PHP да комуникира с MySQL.
* **Достъп:** Настроен е да приема заявки на порт `8080` (мапнат към порт `80` в контейнера).
* **Публикуван образ:** Готовият Docker образ е качен в Docker Hub: [kris22414/kursova-web](https://hub.docker.com/r/kris22414/kursova-web)

### 2. Сървър за база данни (`db`)
* **Основа:** `mysql:8.0`.
* **Съхранение на данните:** Използва се именуван обем (`mysql_data`), за да се предотвратят загуби на информация при спиране или премахване на контейнера.

---

## Връзка и комуникация между услугите

Двата контейнера споделят обща виртуална мрежа, автоматично създадена от Docker Compose.

В конфигурационния файл `src/db.php` връзката с базата данни се осъществява динамично чрез проверка на променливите на средата:
```php
$host = "db";
$dbname = "kursova_2";
$user = "root";
$password = "1234";
```

---

## Начин на стартиране

За да сглобите и стартирате проекта във вашата локална среда:

1. Клонирайте проекта и отворете терминала в главната му папка.
2. Стартирайте услугите във фонов режим чрез Docker Compose:
   ```bash
   sudo docker compose up -d
   ```
3. При първоначално стартиране базата данни се инициализира автоматично чрез скрипта в `db_init/`.
   ```bash
   sudo docker exec -i kursova-db-1 mysql -u root -p1234 kursova < kursova_2.sql
   ```
4. Достъпете приложението през браузъра си на адрес:
   ```text
   http://localhost:8080/src/index.php
   ```

---

## Спиране на проекта

За да спрете работещите контейнери и да освободите системните ресурси, изпълнете:
```bash
sudo docker compose down
```
